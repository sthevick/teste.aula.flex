Guia rápido de Flexbox

1. Introdução ao Flexbox

Flexbox é um modelo CSS utilizado para organizar elementos em linhas ou colunas, facilitando a criação de layouts responsivos e o alinhamento de componentes.

2. Flex Container e Flex Items

O elemento pai se torna um Flex Container com display: flex. Seus filhos diretos tornam-se Flex Items.
